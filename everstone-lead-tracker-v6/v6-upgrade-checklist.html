0 চাবিগুলো বদলে নাও — ৫ মিনিট, বাদ দিও না

কেন: v5-এর Code.gs ফাইলটায় তোমার password, Telegram token আর OpenRouter key সরাসরি লেখা ছিল — আর ওই ফাইলটা GitHub-এ public হয়ে আছে। বট প্রতিদিন public repo স্ক্যান করে key খুঁজে বেড়ায়। ধরে নাও তিনটাই ফাঁস হয়ে গেছে।
OpenRouter key — openrouter.ai → Keys → পুরোনোটা Revoke → নতুন একটা Create করে কপি করে রাখো
Telegram token — Telegram-এ @BotFather-কে লেখো /revoke → বট সিলেক্ট করো → তারপর /token দিয়ে নতুনটা নাও
App password — নতুন একটা ঠিক করো (পুরোনোটাও চলবে, তবে সেটা অনেকদিন public ছিল)

Google client ID গোপন জিনিস নয় — ওটা বদলানোর দরকার নেই।

3 চাবিগুলো নিরাপদ জায়গায় সরাও — ৩ মিনিট

এই ধাপটাই ঠিক করে দেয় যে ভবিষ্যতে GitHub-এ আর কোনোদিন key যাবে না।

ফাইলের উপরের দিকে SETUP_ONCE ব্লকটা খুঁজে বের করো (লাইন ~৬১)। ভেতরে তোমার নতুন মানগুলো বসাও:
var SETUP_ONCE = {

  ALLOWED_EMAILS:     'mdnayemyuzzaman@gmail.com',
  GOOGLE_CLIENT_ID:   '422131638474-c1edadg05ftcegb3ht0b4clrdbqdlhoi.apps.googleusercontent.com',
  TG_TOKEN:           'BotFather থেকে নেওয়া নতুন token',
  TG_CHAT_ID:         '6634894339',
  OPENROUTER_API_KEY: 'openrouter থেকে নেওয়া নতুন key'
};
Ctrl+S সেভ করো
Sheet-এর ট্যাবে ফিরে যাও আর পেজটা রিলোড করো (F5) — না করলে নতুন মেনু আইটেম দেখাবে না
মেনু: Lead Tracker → 2 Move secrets into Script Properties
প্রথমবার permission চাইবে — Allow করো। একটা বক্সে দেখাবে কোনগুলো সরানো হলো।
খুব জরুরি: Apps Script-এ ফিরে গিয়ে SETUP_ONCE-এর সব মান আবার ফাঁকা করে দাও ('') আর সেভ করো
এখন থেকে key গুলো Apps Script প্রজেক্টের নিজের storage-এ আছে, ফাইলে নয়। ফাইলটা এখন GitHub-এ দেওয়া সম্পূর্ণ নিরাপদ।

9 Google sign-in — যদি এখনো কাজ না করে

৯০% ক্ষেত্রে কারণ একটাই: Google Cloud Console-এ তোমার সাইটের origin যোগ করা নেই। v6 এখন সাইন-ইন বক্সেই লিখে দেবে ঠিক কোন কারণে আটকাচ্ছে — আগে চুপচাপ কিছুই দেখাতো না।
console.cloud.google.com → APIs & Services → Credentials
তোমার OAuth 2.0 Client ID-তে ক্লিক করো → Authorised JavaScript origins → ADD URI
হুবহু এটা বসাও — শেষে slash নেই, কোনো path নেই:
https://everstonedigital-lead-tracker.netlify.app
Save → ৫ মিনিট অপেক্ষা করো (Google-এর propagate হতে সময় লাগে) → hard refresh
